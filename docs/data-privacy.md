# Data & Privacy

## Privacy Rules

* No raw image persistence
* Minimize stored user data
* Use anonymization when possible

---

## Streaming

* Use Flux<String>
* Deliver via Server-Sent Events (SSE)

## Evaluation

## Observability

* Log AI responses carefully
