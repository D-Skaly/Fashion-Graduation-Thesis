# Architecture Decision Records (ADR)

## Purpose

This folder contains Architecture Decision Records (ADRs) that document important architectural decisions made during the project.

## What is an ADR?

An ADR is a document that captures a decision made regarding a significant architectural concern. Each ADR should:

* Describe the context and problem
* Explain the decision made
* Justify why this decision was made
* Note consequences (positive and negative)

## Naming Convention

Use the format: `ADR-XXX-short-title.md`

Example: `ADR-001-spring-modulith-choice.md`

## Template

See `ADR-TEMPLATE.md` for the standard format.
