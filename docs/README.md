# Development Guide for Agents (2026)

## Overview

This documentation is designed for:

* AI Agents (code generation, refactor, audit)
* Developers working in modular monolith systems

## Tech Stack

* Java 21 + Spring Boot 3 + Spring Modulith
* Spring AI 1.0
* Next.js (Frontend)
* NestJS (AI Orchestrator)
* FastAPI (AI Service)

* Privacy-first system
