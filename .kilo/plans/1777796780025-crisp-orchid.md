# Kế Hoạch Cài Đặt MCP Servers Toàn Cục Cho Dự Án Fashion E-Commerce

## 1. Phân Tích MCP Servers Cần Thiết

Dựa trên phân tích dự án Fashion E-Commerce (Java 21, Spring Boot 3.3.x, PostgreSQL, Redis, Docker, Next.js), các MCP servers sau đây là cần thiết:

### 1.1. PostgreSQL MCP Server
**Mục đích:**
- Truy vấn trực tiếp cơ sở dữ liệu PostgreSQL để kiểm tra dữ liệu
- Kiểm tra cấu trúc schema và các bảng pgvector
- Hỗ trợ debug các vấn đề liên quan đến dữ liệu
- Thực hiện các truy vấn kiểm thử mà không cần thông qua API

**Tương thích:**
- Hệ điều hành: Windows (win32) ✅
- Yêu cầu: Node.js 20+ (đã có trong dự án)
- PostgreSQL 15+ với pgvector (đã cấu hình trong docker-compose.yml) ✅

### 1.2. Redis MCP Server
**Mục đích:**
- Kiểm tra trạng thái cache Redis
- Debug các vấn đề liên quan đến cache
- Xem các keys và values trong Redis store
- Theo dõi hiệu suất cache

**Tương thích:**
- Hệ điều hành: Windows (win32) ✅
- Redis 7 (đã cấu hình trong docker-compose.yml) ✅
- Yêu cầu: Node.js 20+ ✅

### 1.3. GitHub MCP Server
**Mục đích:**
- Quản lý repository thông qua API
- Tạo và quản lý Issues, Pull Requests
- Xem lịch sử commits và branches
- Tích hợp với GitHub Actions CI/CD đã cấu hình

**Tương thích:**
- Hệ điều hành: Windows (win32) ✅
- Yêu cầu: GitHub token
- Đã có workflow CI trong `.github/workflows/ci.yml` ✅

### 1.4. Docker MCP Server
**Mục đích:**
- Quản lý containers (postgres, redis, minio, ai-service)
- Kiểm tra logs của các services
- Quản lý Docker images và volumes
- Tương tác với docker-compose.yml đã có

**Tương thích:**
- Hệ điều hành: Windows (win32) với Docker Desktop ✅
- Docker Engine 20.10+ (khuyến nghị trong DEPLOY.md) ✅
- Docker Compose 2.0+ ✅

### 1.5. Filesystem MCP Server
**Mục đích:**
- Cung cấp khả năng truy cập file nâng cao
- Hỗ trợ các thao tác file phức tạp
- Bổ sung cho các công cụ read/write/edit hiện có

**Tương thích:**
- Hệ điều hành: Windows (win32) ✅
- Yêu cầu: Node.js 20+ ✅

### 1.6. Fetch MCP Server
**Mục đích:**
- Truy xuất nội dung web để nghiên cứu tài liệu
- Hỗ trợ việc tìm kiếm thông tin kỹ thuật
- Tải xuống tài nguyên bên ngoài

**Tương thích:**
- Hệ điều hành: Windows (win32) ✅
- Yêu cầu: Node.js 20+ ✅

## 3. Kế Hoạch Cài Đặt Toàn Cục (Global)

### 3.1. Cài đặt qua npm (Node.js-based MCP Servers)

Tất cả các MCP servers dưới đây sẽ được cài đặt toàn cục qua npm:

```powershell
# 1. PostgreSQL MCP Server (TypeScript version)
npm install -g @modelcontextprotocol/server-postgres

# 2. Redis MCP Server
npm install -g @modelcontextprotocol/server-redis

# 3. GitHub MCP Server
npm install -g @modelcontextprotocol/server-github

# 4. Docker MCP Server
npm install -g @modelcontextprotocol/server-docker

# 5. Filesystem MCP Server
npm install -g @modelcontextprotocol/server-filesystem

# 6. Fetch MCP Server
npm install -g @modelcontextprotocol/server-fetch
```

### 3.2. Cài đặt qua pip (Python-based MCP Servers - Tùy chọn)

Một số MCP servers có thể được viết bằng Python (như stuzero/pg-mcp-server):

```powershell
# Cài đặt pip (nếu chưa có)
python -m pip install --upgrade pip

# Cài đặt PostgreSQL MCP Python version (tùy chọn)
pip install pg-mcp-server
```

### 3.3. Cài đặt Spring Boot MCP Server (Tùy chọn - Dành cho Spring AI)

Dự án đã sử dụng Spring AI 1.0 với Java 21. Có thể xây dựng MCP server tùy chỉnh:

```powershell
# Clone và build Spring Boot MCP server (nếu cần)
cd D:\CodeFile\Fashion-Graduation-Thesis
git clone https://github.com/nagachary/spring_boot_ai_mcp_server.git temp-mcp
cd temp-mcp
mvn clean install -DskipTests
```

## 4. Cấu Hình MCP Servers

### 4.1. Tạo file cấu hình MCP toàn cục

Tạo file cấu hình tại `C:\Users\DELL\.config\kilo\mcp-config.json`:

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "jdbc:postgresql://localhost:5432/fashion_db_dev",
        "POSTGRES_USER": "fashion_user",
        "POSTGRES_PASSWORD": "fashion_pass"
      }
    },
    "redis": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-redis"],
      "env": {
        "REDIS_URL": "redis://localhost:6379"
      }
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_YOUR_TOKEN_HERE"
      }
    },
    "docker": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-docker"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem"],
      "args": ["D:\\CodeFile\\Fashion-Graduation-Thesis"]
    },
    "fetch": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-fetch"]
    }
  }
}
```

### 4.2. Cấu hình biến môi trường

Tạo file `.env` cho MCP servers tại `C:\Users\DELL\.config\kilo\.mcp-env`:

```bash
# PostgreSQL
DATABASE_URL=jdbc:postgresql://localhost:5432/fashion_db_dev
POSTGRES_USER=fashion_user
POSTGRES_PASSWORD=fashion_pass

# Redis
REDIS_URL=redis://localhost:6379

# GitHub
GITHUB_TOKEN=ghp_your_github_personal_access_token

# MinIO (cho tương lai)
MINIO_ENDPOINT=http://localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
```

## 6. Phương Án Dự Phòng Khi Gặp Lỗi

### 6.1. Lỗi npm install -g (Permission Denied)

**Nguyên nhân:** Không có quyền ghi vào thư mục global npm

**Giải pháp:**
```powershell
# Cấu hình thư mục global npm tùy chỉnh
npm config set prefix "C:\Users\DELL\npm-global"

# Thêm vào PATH
$env:PATH += ";C:\Users\DELL\npm-global\bin"

# Hoặc chạy PowerShell với quyền Administrator
```

### 6.2. Lỗi Node.js version không tương thích

**Nguyên nhân:** MCP servers yêu cầu Node.js 18+ hoặc 20+

**Giải pháp:**
```powershell
# Kiểm tra version
node --version

# Nếu < 18, cập nhật Node.js từ https://nodejs.org/
# Hoặc sử dụng nvm-windows để quản lý nhiều version
```

### 6.3. Lỗi không kết nối được PostgreSQL

**Nguyên nhân:** PostgreSQL container chưa chạy hoặc thông tin kết nối sai

**Giải pháp:**
```powershell
# Kiểm tra Docker containers
docker-compose ps

# Khởi động lại PostgreSQL
docker-compose up -d postgres

# Kiểm tra logs
docker-compose logs postgres

# Kiểm tra kết nối trực tiếp
psql -h localhost -p 5432 -U fashion_user -d fashion_db_dev
```

### 6.4. Lỗi GitHub MCP Server (Token không hợp lệ)

**Nguyên nhân:** GITHUB_TOKEN sai hoặc hết hạn

**Giải pháp:**
1. Tạo Personal Access Token mới tại: https://github.com/settings/tokens
2. Cập nhật token trong file cấu hình
3. Kiểm tra quyền token: `repo`, `workflow`, `read:org`

### 6.5. Lỗi Docker MCP Server (Docker daemon không chạy)

**Nguyên nhân:** Docker Desktop chưa khởi động

**Giải pháp:**
```powershell
# Kiểm tra Docker daemon
docker info

# Nếu lỗi, khởi động Docker Desktop thủ công
# Hoặc restart Docker Desktop
```

### 6.6. Fallback: Sử dụng MCP servers qua Docker containers

Nếu cài đặt npm gặp vấn đề, có thể chạy MCP servers trong Docker:

```powershell
# PostgreSQL MCP Server trong Docker
docker run -i --rm `
  -e DATABASE_URL=postgresql://fashion_user:fashion_pass@host.docker.internal:5432/fashion_db_dev `
  postgres-mcp-server:latest

# Hoặc sử dụng npx trong Docker
docker run -it --rm -v ${PWD}:/app node:20 `
  npx @modelcontextprotocol/server-postgres
```

## 8. Lệnh Thực Thi Tổng Hợp

### 8.1. Script cài đặt toàn bộ (install-mcp-global.ps1)

Tạo file script tại `D:\CodeFile\Fashion-Graduation-Thesis\install-mcp-global.ps1`:

```powershell
# Install MCP Servers Globally for Fashion E-Commerce Project
Write-Host "=== Bắt đầu cài đặt MCP Servers toàn cục ===" -ForegroundColor Green

# Kiểm tra điều kiện tiên quyết

node --version
if ($LASTEXITCODE -ne 0) {
    Write-Host "LỖI: Node.js chưa được cài đặt!" -ForegroundColor Red
    exit 1
}

Write-Host "`n[2/6] Kiểm tra Docker..." -ForegroundColor Yellow
docker --version
if ($LASTEXITCODE -ne 0) {
    Write-Host "CẢNH BÁO: Docker chưa sẵn sàng" -ForegroundColor Yellow
}

# Cài đặt npm global packages
Write-Host "`n[3/6] Cài đặt PostgreSQL MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-postgres

Write-Host "`n[4/6] Cài đặt Redis MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-redis

Write-Host "`n[5/6] Cài đặt GitHub MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-github

Write-Host "`n[6/6] Cài đặt Docker MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-docker

Write-Host "`n[7/6] Cài đặt Filesystem MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-filesystem

Write-Host "`n[8/6] Cài đặt Fetch MCP Server..." -ForegroundColor Cyan
npm install -g @modelcontextprotocol/server-fetch

# Xác nhận cài đặt
Write-Host "`n=== Xác nhận cài đặt ===" -ForegroundColor Green
npm list -g --depth=0 | Select-String "modelcontextprotocol"

Write-Host "`n=== Hoàn tất cài đặt MCP Servers ===" -ForegroundColor Green
```

### 8.2. Thực thi script
