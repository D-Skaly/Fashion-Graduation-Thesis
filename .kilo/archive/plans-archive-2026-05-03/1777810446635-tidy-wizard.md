## DANH SÁCH ƯU TIÊN (2 VẤN ĐỂ CHÍNH)

### 🔴 VẤN ĐỂ 1: Module `fiagent` chưa tuân thủ cấu trúc 4 lớp (Ưu tiên cao nhất)

**Mô tả vấn đề:**
- Module `fiagent` hiện tại có cấu trúc: `analytics/`, `customer/`, `interfaces/`, `scoring/`
- Không có sự phân chia rõ ràng: `domain/`, `application/`, `infrastructure/`, `interfaces/`
- Các JPA Entities (`Analytics.java`, `CustomerProfile.java`) chứa annotation `@Entity` nằm ngoài `infrastructure/persistence/entities/`
- Service (`ScoringService.java`) nằm trong `scoring/` thay vì `application/`
- DTOs nằm trong `interfaces/` thay vì `application/dto/` hoặc `interfaces/dto/`

**Vị trí hiện tại:**
```
fiagent/
├── analytics/          ← Sai: Chứa cả Entity + Repository
├── customer/           ← Sai: Chứa cả Entity + Repository  
├── interfaces/         ← Đúng: Controllers + DTOs
└── scoring/            ← Sai: Nên ở application/
```

**Cấu trúc đúng chuẩn (Clean Architecture):**
```
fiagent/
├── domain/
│   ├── model/
│   │   ├── Analytics.java              (Thuần Java, KHÔNG @Entity)
│   │   ├── CustomerProfile.java       (Thuần Java, KHÔNG @Entity)
│   │   └── ScoredProduct.java
│   └── repository/
│       ├── AnalyticsRepository.java    (Interface only)
│       └── CustomerProfileRepository.java (Interface only)
├── application/
│   ├── service/
│   │   └── ScoringService.java
│   └── dto/
│       ├── BatchScoringRequest.java
│       ├── ProductCandidateResponse.java
│       └── StyleVectorSearchRequest.java
├── infrastructure/
│   └── persistence/
│       └── jpa/
│           ├── AnalyticsEntity.java        (Có @Entity)
│           ├── CustomerProfileEntity.java (Có @Entity)
│           ├── JpaAnalyticsRepository.java
│           ├── JpaCustomerProfileRepository.java
│           └── FiAgentPersistenceMapper.java
└── interfaces/
    └── rest/
        └── FiAgentController.java
```

### 🔴 VẤN ĐỂ 2: `SpringAiEmbeddingModelAdapter` sai vị trí

**Mô tả vấn đề:**
- File hiện tại: `common/infrastructure/SpringAiEmbeddingModelAdapter.java`
- Vị trí đúng: `ai/infrastructure/SpringAiEmbeddingModelAdapter.java`
- Lý do: Embedding là AI concern, không phải common concern
- Port `EmbeddingModelPort` nằm ở `common/port/` là chấp nhận được (shared kernel)
- Nhưng adapter implementation phải nằm trong module sử dụng nó (ai module)

**Vị trí hiện tại:** `common/infrastructure/SpringAiEmbeddingModelAdapter.java` ❌
**Vị trí đúng:** `ai/infrastructure/SpringAiEmbeddingModelAdapter.java` ✅

## PHƯƠNG ÁN GIẢM THIỂU RỦI RO

### Rủi ro 1: Breaking Changes khi refactor fiagent
**Mức độ:** 🔴 Cao
**Khả năng xảy ra:** 60%

**Phương án giảm thiểu:**
1. **Branch strategy:** Tạo branch `refactor/fiagent-structure` từ `main`
2. **Incremental migration:** 
   - Bước 1: Tạo cấu trúc mới song song với cấu trúc cũ
   - Bước 2: Update controllers để dùng services từ package mới
   - Bước 3: Xóa code cũ sau khi verify
3. **Database safety:** 
   - Không thay đổi tên bảng (giữ nguyên `@Table(name = "analytics")`)
   - Flyway migrations không đổi (đã có V1-V6)
4. **Rollback plan:** 
   - Nếu có lỗi, revert commit và switch về `main`
   - Giữ backup của các file gốc

### Rủi ro 2: Spring Context không scan đúng packages
**Mức độ:** 🟡 Trung bình
**Khả năng xảy ra:** 30%

**Phương án giảm thiểu:**
1. **Verify `@SpringBootApplication` scan:**
   ```java
   @SpringBootApplication(scanBasePackages = "com.skaly.fashion_backend")
   public class FashionBackendApplication { ... }
   ```
2. **Test sau mỗi bước:**
   - Sau khi di chuyển `Analytics.java`: `./mvnw test -Dtest=Analytics*`
   - Sau khi di chuyển `ScoringService.java`: `./mvnw test -Dtest=Scoring*`
3. **Check component scanning:**
   - Đảm bảo `@Service`, `@Repository`, `@Entity` annotations đúng vị trí

### Rủi ro 3: Mất dữ liệu hoặc schema incompatibility
**Mức độ:** 🟢 Thấp
**Khả năng xảy ra:** 10%

**Phương án giảm thiểu:**
1. **Database backup:**
   ```bash
   pg_dump fashion_db_dev > backup_before_refactor.sql
   ```
2. **Giữ nguyên Flyway migrations:** Không sửa V1-V6
3. **Test với testcontainer:** Integration tests sử dụng testcontainers

### Rủi ro 4: Performance degradation (parallel stream trong ScoringService)
**Mức độ:** 🟡 Trung bình
**Khả năng xảy ra:** 20%

**Phương án giảm thiểu:**
1. **Benchmark trước và sau:**
   ```java
   // Trước refactor
   // 1000 products: ~50ms
   
   // Sau refactor
   // 1000 products: ~50ms (phải tương đương)
   ```
2. **Cấu hình PARALLEL_THRESHOLD:**
   - Hiện tại: 250
   - Có thể cần điều chỉnh tùy theo performance test

### Rủi ro 5: EmbeddingModelPort conflicts
**Mức độ:** 🟢 Thấp
**Khả năng xảy ra:** 15%

**Phương án giảm thiểu:**
1. **Verify port interface:** Đảm bảo `EmbeddingModelPort` trong `common/port/` không bị thay đổi
2. **Update references:** Kiểm tra tất cả nơi sử dụng `SpringAiEmbeddingModelAdapter`
